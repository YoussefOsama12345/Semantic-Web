# Semantic-Web

Semantic Movie Recommendation System — a university project for a Semantic Web
& Ontology course. Built in Java with an OWL ontology, SPARQL queries, SWRL
rules, the HermiT reasoner and a minimalist Java Swing UI.

The full application lives in [`movie-recommender/`](movie-recommender/). See
[`movie-recommender/README.md`](movie-recommender/README.md) for build / run
instructions and design details.
